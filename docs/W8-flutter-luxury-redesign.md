# W8 — Flutter Premium Luxury Redesign

## الهدف

تمت إعادة بناء طبقة العرض في تطبيق **CarRental.Mobile** من واجهة Material تقليدية إلى تجربة **Premium Luxury** مع الحفاظ على البنية متعددة الطبقات، ومسارات التنقل، والمصادقة بـ JWT، وربط Web API.

## لغة التصميم

تعتمد الهوية الجديدة على لوحة **Midnight Navy** للخلفيات الرئيسية، و**Champagne Gold** للأفعال والعناصر المميزة، و**Ivory** للخلفيات والأسطح. تم استخدام زوايا ناعمة، حدود خفيفة، ظلال هادئة، وتدرجات داكنة لإظهار الطابع الراقي دون التأثير على وضوح النص العربي.

| العنصر | الاستخدام |
|---|---|
| `AppTheme.midnight` | شاشة الدخول، Drawer، بطاقات الصور، شريط التنقل |
| `AppTheme.primary` | الأزرار، الأسعار، الشارات، الأيقونات المهمة |
| `AppTheme.primaryLight` | النصوص الذهبية فوق الخلفيات الداكنة |
| `AppTheme.background` | خلفية صفحات التطبيق |
| `AppTheme.surface` | البطاقات والنماذج والحوارات |
| `LuxuryHero` | مقدمات الصفحات ذات التدرج الداكن |
| `LuxurySurface` | بطاقة موحدة بحدود وظل خفيف |
| `LuxuryMetric` | مؤشرات الأسطول والحجوزات |
| `LuxuryStatusChip` | حالات السيارات والحجوزات |
| `LuxuryEmptyState` | حالات عدم وجود بيانات والأخطاء |

## الشاشات المعاد تصميمها

### شاشة الدخول

تتضمن علامة CAR RENTAL، عنوانًا افتتاحيًا فاخرًا، بطاقة تسجيل دخول بيضاء فوق خلفية Midnight، زر دخول آمن، ومؤشر اتصال مشفر. تم الحفاظ على التحقق من اسم المستخدم وكلمة المرور واستدعاء `AuthController.login`.

### الهيكل الرئيسي

تم تحويل التطبيق إلى هيكل تنقل واضح يضم Top Bar مختصرًا، صورة المستخدم، Drawer داكنًا، وNavigation Bar داكنًا بمؤشر ذهبي. المسارات الثلاثة هي الأسطول، الحجوزات، والحساب.

### شاشة السيارات

تتضمن Hero Section، مؤشرات عدد الأسطول والسيارات الجاهزة، فلاتر الكل والمتاحة والمؤجرة، وبطاقات مركبات كبيرة تركز على الصورة والعلامة والسعر والحالة. الضغط على البطاقة يفتح تفاصيل مختصرة في Bottom Sheet.

### شاشة الحجوزات

تتضمن مؤشرات إجمالي الحجوزات والرحلات النشطة، فلاتر الحالة، بطاقات تعرض السيارة والعميل والفترة والقيمة الإجمالية، بالإضافة إلى تدفق إنشاء حجز داخل Bottom Sheet فاخر مع اختيار السيارة والعميل والتواريخ.

### شاشة الحساب

تتضمن بطاقة هوية داكنة، حالة الجلسة، لغة التطبيق، معلومات الأمان، وزر تسجيل خروج واضح باستخدام `AuthController.logout`.

## الحفاظ على الوظائف

لم يتم تغيير عقود البيانات أو طبقة الاتصال. ما زالت الشاشات تستخدم `AppScope` و`CarsController` و`RentalsController` و`AuthController` و`CustomerRepository`. لذلك يظل JWT، واستدعاء السيارات، واستدعاء الحجوزات، وإنشاء الحجز، وتسجيل الخروج مرتبطة بنفس Web API.

## التحقق

تم تنفيذ `git diff --check` بنجاح ولم تظهر مسافات زائدة أو أخطاء تنسيق في الفروقات. لم يكن Flutter SDK متوفرًا في بيئة التنفيذ، لذلك يجب إكمال التحقق على جهاز التطوير عبر:

```powershell
cd CarRental\CarRental.Mobile
flutter pub get
flutter analyze
flutter test
flutter run
```

## ملاحظات التشغيل

تأكد من تعديل عنوان API في `lib/core/api_config.dart` بما يناسب بيئة التشغيل. في محاكي Android يستخدم عادةً `10.0.2.2` للوصول إلى خادم الجهاز المضيف، بينما قد يحتاج الجهاز الحقيقي إلى عنوان IPv4 المحلي للجهاز الذي يشغّل Web API.
